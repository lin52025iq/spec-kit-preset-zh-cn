# Changelog

All notable changes to this preset will be documented in this file.

The project follows Semantic Versioning.

## 0.0.3

- Prepare the Simplified Chinese preset for submission to the official Spec Kit Community Presets catalog.
- Document installation using the immutable `v0.0.3` tag archive.
- Clarify when to use and when not to use the preset.
- Keep five localized core templates and nine Simplified Chinese command wrappers.
- Preserve machine-readable identifiers, code symbols, file paths, HTTP methods, API routes, and other technical contracts.
- Require Spec Kit CLI `>=1.0.5.dev0`.

## 0.2.0

- Localize the five core Spec Kit templates to Simplified Chinese.
- Add Simplified Chinese wrappers for `speckit.specify`, `speckit.clarify`, `speckit.plan`, `speckit.tasks`, `speckit.checklist`, `speckit.analyze`, `speckit.constitution`, `speckit.implement`, and `speckit.converge`.
- Preserve machine-readable identifiers, code symbols, file paths, HTTP methods, API routes, and other technical contracts.
- Use `wrap` command overrides so the preset can inherit upstream core command changes where possible.
- Set the minimum compatible Spec Kit CLI version to `1.0.5.dev0`.
