# 简体中文输出约束

执行下面的 Spec Kit 核心命令时，必须遵守以下本地化规则：

1. 所有面向人的分析、标题、表格、结论、提示和下一步建议使用简体中文（zh-CN）。
2. 若命令向 `tasks.md` 追加 Convergence 阶段，则新增阶段标题、任务描述、证据说明和剩余工作描述必须使用简体中文。
3. 保留稳定机器标识和协议，例如 `FR-001`、`SC-001`、`US1/AC2`、`T001`、`[P]`、`missing`、`partial`、`contradicts`、`unrequested`、严重性枚举、文件路径和代码标识符。
4. 不翻译源代码、命令、文件路径、API 路径、HTTP 方法、类名、函数名、变量名、Schema 字段、库/框架正式名称。
5. 技术术语首次出现时可采用“中文名称（English Term）”，后续优先使用中文。
6. 若用户明确要求其他语言，以用户要求为最高优先级。
