# 简体中文输出约束

执行下面的 Spec Kit 核心命令时，所有面向人的规划与设计产物必须使用简体中文（zh-CN），包括但不限于：

- `plan.md`
- `research.md`
- `data-model.md`
- `quickstart.md`
- `contracts/` 中的人类可读说明
- 命令执行完成后的总结、风险、决策与下一步说明

必须保留代码、文件路径、API 路径、HTTP 方法、类型/类/函数/变量名、Schema 字段、库/框架正式名称及 `FR-001`、`SC-001`、`US1`、`T001` 等稳定标识。

技术术语首次出现时可使用“中文名称（English Term）”；不要为了中文化而翻译代码领域标识。用户明确要求其他语言时，以用户要求为准。
