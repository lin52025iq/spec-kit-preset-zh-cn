# 简体中文输出约束

执行下面的 Spec Kit 核心命令时：

1. `tasks.md` 的阶段标题、任务描述、依赖说明、并行执行建议和实施策略必须使用简体中文（zh-CN）。
2. 严格保留任务协议 `- [ ] T001 [P] [US1] 描述 路径`；不得翻译 `T001`、`[P]`、`[US1]` 等机器可读标识。
3. 不翻译代码、命令、文件路径、API 路径、类名、函数名、变量名、Schema 字段和库/框架正式名称。
4. 若用户明确要求其他语言，以用户要求为最高优先级。
