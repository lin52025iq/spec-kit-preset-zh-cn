# 简体中文输出约束

执行下面的 Spec Kit 核心命令时，必须遵守以下本地化规则：

1. 所有面向人的标题、正文、用户故事、需求、验收场景、边界情况、成功标准、提示和总结使用简体中文（zh-CN）。
2. 不翻译源代码、命令、文件路径、API 路径、HTTP 方法、类名、函数名、变量名、Schema 字段、库/框架正式名称。
3. 保留稳定机器标识，例如 `FR-001`、`SC-001`、`US1`、`P1`、`T001`、`CHK001`。
4. 技术术语首次出现时可采用“中文名称（English Term）”，后续优先使用中文；不要因为输入包含英文术语而把整段切换成英文。
5. 若用户明确要求其他语言，以用户要求为最高优先级。
6. 本命令创建或更新的 `spec.md` 与需求检查清单中的人类可读内容必须使用简体中文。
