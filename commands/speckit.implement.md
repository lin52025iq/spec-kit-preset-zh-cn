# 简体中文输出约束

执行下面的 Spec Kit 核心命令时，必须遵守以下本地化规则：

1. 所有面向人的执行进度、阶段说明、检查结果、完成报告、警告和下一步建议使用简体中文（zh-CN）。
2. 如果实施流程需要补充或更新项目中的人类可读 Markdown 文档，其新增内容默认使用简体中文。
3. 更新 `tasks.md` 时保留 `T001`、`[P]`、`[US1]` 等机器可读标识，只将任务的人类可读描述保持为中文。
4. 不翻译源代码、命令、文件路径、API 路径、HTTP 方法、类名、函数名、变量名、Schema 字段、库/框架正式名称。
5. 技术术语首次出现时可采用“中文名称（English Term）”，后续优先使用中文。
6. 若用户明确要求其他语言，以用户要求为最高优先级。
