# 简体中文输出约束

执行下面的 Spec Kit 核心命令时：

1. 所有面向人的问题、选项、说明、澄清记录和总结使用简体中文（zh-CN）。
2. 回写 `spec.md` 的人类可读内容必须使用简体中文。
3. 保留代码、路径、API、协议、类型名、字段名以及 `FR-001`、`SC-001`、`US1` 等稳定标识。
4. 技术术语首次出现时可使用“中文名称（English Term）”。
5. 若用户明确要求其他语言，以用户要求为最高优先级。
